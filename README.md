# 但丁式情感分析 Skill（danding-skill v1.0）

> 把「但丁」的两性与情感方法论，蒸馏成一个可被 AI 执行的技能包。
> 它不提供通用话术，而是一套**先归因、再给路径**的分析流程。

## 这是什么

一段聊天记录、一句"她这么说是什么意思"、一次约不出来——大多数建议之所以无效，是因为没判断问题出在哪一层就开始给招。

这个 skill 解决的是**归因**问题：

1. 还原事实：把"她说的"和"她做的"分开；
2. 分层归因：心态层 → 关系层 → 对方层 → 话术层，上层没修，下层无效；
3. 调取依据：按路由表最多读 2 个参考文件 + 2 条案例；
4. 结构化输出：判断 / 依据 / 替代反应（必含一个"不做什么"）/ 边界。

## 设计要点

- **四层归因有顺序。** 心态问题没排除之前，不跳到话术层。
- **阅读有配额。** 每次最多 2 个 reference + 2 条案例，防止把书堆给对方。
- **案例是校准器，不是答案库。** 只借分析和判断，不复制台词。
- **必须给"不做什么"。** 沉默、不回复、主动结束、降低投入，至少出现一个。
- **拒绝类场景不引操作案例。** 明确拒绝、醉酒、被欺骗、涉及安全时，直接说明"这条路为什么不走"。
- **分型只是假设。** 女性分型必须用对方的行为验证，不能当作定论。

## 安装与使用

作为 Claude Code 的 personal skill 安装：

```bash
git clone https://github.com/vincent3798/danding-skill.git ~/.claude/skills/danding
```

Windows 默认路径为 `C:\Users\<用户名>\.claude\skills\danding\`。也可以放到某个项目的 `.claude/skills/danding/` 下，只在那个项目生效。

安装后在对话里直接描述场景即可触发，例如：

- "她已读不回三天了，还有戏吗？"
- "刚加的女生，我发消息她只回一个'哦'，怎么回？"
- "我好像一直在讨好她，怎么办？"

## 输出示例

**输入**

> 刚加的女生，我发"今天好累啊"，她只回了一个"哦"。

**输出（节选）**

1. **判断**——不是她冷淡，是你在第一轮就向她索取情绪价值。问题在心态层，还不到话术层。
2. **依据**——A5：需求感是"索取"，不是"喜欢"；A2：关系进度由她的投入决定，不由你的付出决定。
3. **替代反应**——
   - 换一个有信息量的开场（分享具体的事，以状态说，不带问号）；
   - 不回复，等她主动或下次自然接触（不做）；
   - 直接推进到具体邀约，用行动测试兴趣。
4. **边界**——如果她已经连续两次无视，或此前已明确拒绝，以上都不成立，按危机层处理。

## 边界与免责

本 skill 明确不用于、也不生成：

- 欺骗、冒充身份、制造恐慌、摧毁对方自尊的话术；
- 纠缠、跟踪、骚扰、报复、曝光隐私、向对方施压；
- 针对未成年人的任何内容；
- 趁虚而入（对方醉酒、情绪崩溃、重大打击期间）；
- 把明确的拒绝解释成"欲擒故纵"或"在考验你"。

遇到以上需求，skill 会直接说明这条路走不通，并给出替代方向。
