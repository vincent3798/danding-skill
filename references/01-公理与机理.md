# 公理、术语与机理

> 这是整个技能的底座：术语定义、公理、机理、五本书的冲突裁决都在这里。
> **它不是每次必读**——只在三种情况下打开：术语拿不准、几本书说法冲突、或者想知道某个判断的原书依据。

## 一、公理

判断一个场景时，先在这些公理上对齐，再谈具体做法。

**A1｜吸引是情绪，不是逻辑结论。**
你无法在逻辑上说服一个人喜欢你，只能制造让她产生情绪的经验。她事后给出的理由（"他很幽默""他对我好"）是事后编的，不是原因。〔书2 导语；书4 第四章〕

**A2｜她对你投入多少，决定她有多喜欢你。**
不是你的条件多好，也不是你对她多好。一个人为自己已付出的东西辩护，是本能。〔书2 第一部分；书5 序言〕

**A3｜"投资"是双向概念，最常被搞反。**
你为她付出 → 你更喜欢她。她为你付出 → 她更喜欢你。所以"我对她好、我花钱"不产生吸引，只是讨好。〔书2 第一部分；书3 第三部分第一章〕

**A4｜逆向合理化：先有行为，后有理由。**
人做出行为后会替自己补一个逻辑理由。因此顺序是"先制造行为，感情随后被合理化出来"。方向可正可负——事后你补安全感，她合理化为"他值得"；事后你冷淡，她合理化为"我被玩了"。〔书4 第四章；书2 第四部分〕

**A5｜需求感不是"喜欢她"，是"索取"。**
查户口式提问、过度关心生活、急于证明、要一个确定答案、心情随她的反应起伏——这些才是需求感。喜欢本身不是问题，求结果才是。〔书2；书3 第三章〕

**A6｜她说的话是当下情绪，行动才是信息。**
判断兴趣只看：是否主动联系、是否赴约、是否接受肢体推进、是否为你做事。口头夸奖成本极低，可以出于礼貌、也可以是为了吊着你。〔书4 第六章；书1 第三章；案例库母题 1〕

**A7｜潜沟通优先于话术。**
对方读取的是你的内在状态，不是你的台词。背得再熟，一次意外反应就会泄漏。〔书4 第一章〕
推论：先改状态，再改话术；只改话术会长期卡住。

**A8｜框架：谁在解释、谁在追、谁的情绪被牵动，谁就低位。**
被质疑时急于解释，等于承认对方的议题有效。不接议题、另设议题，才可能反转。〔书1 第十四章；书4 第三章〕

**A9｜阶段不可跳跃，也不可久留。**
熟悉 → 暧昧 → 亲密。跳级会触发防御；在任一阶段停太久，越难进入下一阶段。已存在的熟悉度（旧识、同圈）可以跳步。〔书2 第一部分；书2 第二部分〕

**A10｜挑战性不等于冷漠。**
有效的"挑战"是：表达过好感之后，行为仍然如常。无效的是：全程装拽、对所有人冷漠。〔书5 第一部分第一章〕

**A11｜越想证明，价值越低。**
证明的动机是不安全感，而不安全感会被读出来。〔书4 第六章；书1 第三章〕
"失败者求而不得，胜利者不求而得。"

**A12｜技巧只能制造"被吸引的感觉"，制造不了"愿意一起生活"。**
它对不在意的对象高效，对真正在意的对象反而失效。〔书1 第十二章〕

**A13｜长期关系里，谁更敢失去，谁就掌握权力。**
不敢失去的一方，每次情绪纠缠都是在投资。〔书2 附录〕

**A14｜终点是不执著、不闪躲、不炫耀、不证明。**
这是作者自己在最后一本书里给下的定论。所有前面的话，都服务于这一条，而不是相反。〔书1 第十七、十八章〕

## 二、术语的专有定义

这些词在日常中文里有别的意思，在这个体系里必须按下面的定义用。

| 术语 | 专有含义 | 最常被误读成 |
|---|---|---|
| 投资 | 为对方付出的时间、精力、金钱、情绪、约见、暧昧回应、肢体。分"你投入"与"她投入"，后者才制造吸引 | "我对她好" |
| 需求感 | 索取价值、急于证明、索要确定性的行为，外显为情绪随对方反应起伏 | "喜欢一个人" |
| 框架 | 双方默认的互动规则与地位关系；谁被对方的话带走，谁就在框架低位 | 咄咄逼人、争对错 |
| 预选 | 被其他异性公开认可，且不主动炫耀。炫耀即转为负债 | 带美女晒战绩 |
| 逆向合理化 | 对已发生行为的自我辩护，行为越不合逻辑越强 | 事后总结 |
| 潜沟通 | 语言之外泄漏的内在自我评价，对方潜意识读取 | 话术技巧 |
| 挑战性 | 表达好感后行为如常，制造"她不确定你态度"的张力 | 装冷漠、欲擒故纵 |
| 伪自信 / 核心自信 | 伪自信依赖场景与外部条件，换场景即垮；核心自信不随环境波动 | "自信就是相信自己" |
| 测试型 / 投资型 | 作者的女性分类维度之一：身边男人多、倾向筛选利用 ↔ 男人少、倾向长期投入 | 好女人 / 坏女人 |
| 感觉型 / 价值型 | 作者的女性分类维度之一：要浪漫心动 ↔ 要现实价值 | 感性 / 理性 |
| 短线 / 中线 / 长线 | 按"吸引度 + 熟悉度"划分的关系节奏，不是按认识时长 | 恋爱周期 |
| 心锚 | 把某种情绪状态与"你出现"绑定 | 心理操控 |
| 爱的语言错配 | 你给"服务/价值"，她要"肯定/浪漫"，双方都没错但接不上 | 不合适 |

> 女性分型（测试型/投资型 × 感觉型/价值型 × 开放/保守）是**作者的分类模型，不是事实，也不是科学结论**。同一个人在不同场合、不同人生阶段会变。用它做观察假设，不要用它做评价。

## 三、机理链

分析时用来解释"为什么会这样"，也是给建议的依据。

- **M1 逆向合理化**：她为你投入时间、身体、情绪 → 大脑必须为这行为找理由 → 合理化为"我一定喜欢他" → 她过滤掉与这个感觉冲突的证据 → 感觉被加固。反向同样成立。
- **M2 潜沟通泄漏**：内在自我评价 → 无意识微行为（眼神、语速、姿态） → 对方潜意识读取"总体气场" → 情绪反应 → 吸引力升降，几秒内就能改变。
- **M3 身份边界**：自我概念决定"这不是我会做的事" → 遇到超出身份的行为就退缩 → 可能性关闭 → 旧身份被强化。所以只学动作不改身份，会长期卡在原地。
- **M4 参考点 → 焦虑**：内心设一个"我应被如何对待"的标准 → 遇人即比较 → 自我评价下滑 → 焦虑 → 注意力内收只感受自己 → 被读作低价值 → 更被拒 → 更焦虑。
- **M5 回应的滚雪球**：被环境接纳 → 确定感上升 → 放松、不寻求反应 → 别人更愿意给反应 → 价值感再升。这是"社交认证"的机制，但它是伪自信，不等于核心自信。
- **M6 讨好机制**：为让对方喜欢你而做某事 → 潜台词"我不能仅靠自身吸引你" → 对方感知她地位更高、你有需求 → 吸引力下降。
- **M7 拒绝惯性**：每一次被拒绝（哪怕是不回消息）都会累积成"这个人可以拒绝"的惯性 → 所以早期不要索要任何"YES"。
- **M8 心锚**：好心情会与在场者绑定 → 她低落时你的陪伴会与负面情绪绑定 → 只在她状态好时出现，别做情绪垃圾桶。
- **M9 沉没成本**：她为你做的小事越多越倾向继续投入 → 投资要从小到大递增，且永不停止。
- **M10 信息不对称**：一方掌握另一方不知道的关键信息时，被蒙在鼓里者的"自我修正"无效——分手可能根本与其行为无关。〔书1 第七、八章〕
- **M11 第三方可见性**：旁观者用"谁与你同框"推断你的社会位置，比你的自我陈述可信。〔书1 第十六章〕
- **M12 情绪归因倒置**：把坏情绪说成外部造成 → 抱怨、低能量 → 他人远离 → 合理化为"世界不公、女人犯贱" → 更消极。

## 四、判断标准

给建议前，先用这几条读信号。

- **J1 判断真实兴趣**：看她做什么，不看说什么。主动联系、赴约、身体朝向你、语气变软、追问你 —— 是兴趣。夸奖、"你真好""还有戏" —— 不是。
- **J2 判断谁在框架高位**：谁回应更多、谁的情绪被牵动、谁在努力维持对话、谁去追离开的人。
- **J3 判断自己是否在讨好**：自问"如果她明确说不喜欢我，我还想做这件事吗？"答案为否，就是讨好。
- **J4 判断焦虑还是自信**：注意力在自身感受（内收），还是在外部环境。
- **J5 判断真自信还是伪自信**：换到陌生场景还稳不稳。稳不住的，是伪自信。
- **J6 判断对方要求是否无理**：她在用情绪施压（只给态度不给理由），还是在说具体合理的事由。
- **J7 判断关系阶段**：能否自然联系 → 熟悉；是否接受调情与轻度肢体 → 暧昧；是否愿意去安静私密环境 → 亲密。
- **J8 判断该不该继续**：类型已明确为高段位测试型且对你本无好感；或她只索取、从不回应。两条满足其一，就该停。

## 五、五本书的版本关系与冲突裁决

同一作者，不同时期，立场在变。**这是使用这套材料时最容易出错的地方。**

```
书1《多维人生》   经历与故事 —— 案例矿
书2《核心吸引法则》 公理与流程 —— 骨架（早期）
书3《技巧的极致》   具体战术 —— 战术层（早期，最强技巧派）
书4《真相》        底层机理 —— 解释层（中期，开始转向身份）
书5《天使心魔鬼眼》 人格与分型 —— 心法（最晚，主张"技巧＋内在"兼有）
```

**冲突裁决规则**：默认按作者后期立场，优先级为 **书5 > 书4 > 书2 > 书3**。其中书2 排在书3 之前，不是因为时间更晚，而是因为**公理与流程优先于具体战术**——两条冲突时，先按原理走，再套动作。

三处已知冲突，以及裁决：

1. **技巧 vs 身份**。书3 教招式，书5 说"做真实的男人"，并直斥"我如何做 XX 让她 XX"这类提问方式本身就暴露了"我配不上她"。
   → 裁决：用户要具体战术时给书3/动作库，但必须同时指出这只解决当下这一轮，不解决他为什么需要它。**不要用战术掩盖心态问题。**

2. **隐藏意图 vs 坦诚表达**。书3 的关键技巧依赖"不暴露目的"——原话是"在初期，你要更加小心的掩藏意图"；书5 则把"清晰表达意图"当作影响力的核心——"影响力是，强烈和清晰的意图表达"。
   → 裁决：涉及**目的性隐瞒**的做法一律不给（见 SKILL.md 硬规则）；其余"不急于表白"之类属于节奏问题，不算隐藏意图。

3. **"快速亲密可以与吸引无关" vs "吸引是核心"**。书2 第三部分明确写了这一点。
   → 裁决：把这条限定在它本来的范围内——**双方自愿、她随时可以离开、事后要补安全感**。书中自己也写明，一旦限制人身自由或强迫，性质就变了，不再是建议范围内的东西。这条不适用于任何以欺骗、灌醉、趁人之危为手段的场景。

## 六、阶段模型

| 阶段 | 目标状态 | 判断信号 | 常见失败 |
|---|---|---|---|
| 熟悉 | 她与你相处自在，判断你安全、不会损害她利益 | 主动找你、接受约见、愿意讲私事 | 刚认识就展示、吹嘘、查户口、把"假朋友"当真朋友、停留太久不敢破局 |
| 暧昧 | 她默认或回应暧昧话语，接受调情与轻度肢体 | 她不反对，即视为默认；愿意回答筛选式问题；被调侃后有推、打、笑 | 跳级直接聊性；表白成"做我女友吧"；一直暧昧不升级，滑成纯友谊 |
| 亲密 | 身体距离被拉近，牵手、接吻自然发生 | 愿意转移到安静私密环境；独处不设防；接触不被拒 | 公开场合强升级（她要维持矜持）；小心翼翼式触碰；被拒后自我投资 |

**"真朋友"与"假朋友"**：真朋友是有事没事都找你；假朋友是"你适合做我的好朋友"——后者是好人卡的前身，不是熟悉度。
